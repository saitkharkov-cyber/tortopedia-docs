## Решения этой сессии

1. Любой новый рабочий чат начинается только с `START_SESSION.md`.
2. HANDOFF больше не содержит общий стартовый алгоритм, а только напоминает начать с `START_SESSION.md`.
3. ChatGPT обязан сам регулярно отслеживать необходимость обновления `CURRENT_SESSION_STATE.md`.
4. Документация локально переносится внутрь дерева сайта в `D:\Git\tortopedia\docs`.
5. Папка `docs/` игнорируется основным репозиторием сайта и остаётся отдельным вложенным Git-репозиторием документации.
6. Git сайта и Git документации нельзя смешивать.

## Что намеренно не трогаем

- Не объединяем Git-истории сайта и документации в один репозиторий.
- Не включаем документацию в production-сборку сайта.
- Не начинаем следующую контентную статью до завершения синхронизации документации и проверки публикации текущей статьи.
