- для покупной мастики приоритетны рекомендации производителя;
- для домашней — состав и рецепт;
- производители расходятся по холодильнику и заморозке;
- нельзя переносить старые универсальные сроки Tortopedia как общее правило.

## Правило CURRENT_SESSION_STATE.md / HANDOFF

С 2026-09-14 в документации зафиксировано:

- сессия продолжается → использовать `CURRENT_SESSION_STATE.md`;
- работа завершается и контекст передаётся следующему чату → обновлять `HANDOFF`;
- если в конце сессии сразу готовится актуальный HANDOFF, отдельно обновлять `CURRENT_SESSION_STATE.md` не нужно, чтобы не дублировать один и тот же снимок.

## Важно по Git

Перед каждым коммитом:

```powershell
git diff --check
```

затем просмотр содержательного diff и:

```powershell
git status --short
```

Не использовать без необходимости `git add .` и `git add -A`.

Особенно проверять untracked production-файлы после `publish.ps1`, чтобы вся логическая задача попадала в один коммит.

Коммит и push — только по явной команде пользователя.
