## Важно по Git

Сайт и документация остаются разными Git-репозиториями, но локально документация переносится внутрь дерева сайта в `docs/`.

Не смешивать их коммиты.

Перед коммитом сайта:

```powershell
git diff --check
```

затем содержательный diff, `git status --short`, staging конкретных файлов и `git diff --cached --check`.

Commit/push — только по явной команде пользователя.
